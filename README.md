# 김유미 | Portfolio

다양한 직무 지원에 공통으로 사용할 수 있도록 구성한 프로젝트 중심 포트폴리오입니다.

## 프로젝트
- 쉬엄쉬엄 — 위치 기반 휴식공간 검색 및 보행 경로 웹 서비스
- 오늘의짐 — 보관함 추천과 짐 회수를 고려한 동선 비교 (2인 팀 해커톤)
- GIGANG — 웹·DB·단말 이벤트 연동 보안 관제 (팀 프로젝트)
- HTTP Status Pattern Analyzer — HTTP 반복 오류 유형별 로그 분석 도구
- Mini SOC — 로그 수집·탐지·알림·보고 자동화

기존 `About-me`, `popol`, `youmjjang-lab` 자료의 사실관계와 실제 프로젝트 이미지를 참고했습니다. 이미지는 원본 공개 저장소 링크를 사용하기 때문에 원본 이미지를 삭제하면 이 포트폴리오에도 영향을 줍니다.

## 실행
`index.html`을 브라우저에서 열거나 `python -m http.server 8000`으로 실행합니다.

## GitHub Pages
Repository > Settings > Pages > Deploy from a branch > main / (root)

## 파일
- `index.html` — 전체 소개와 프로젝트 카드
- `styles.css` — 반응형 스타일
- `script.js` — 프로젝트 필터와 모바일 메뉴

실제 기업 성과, 검증하지 않은 수치, 팀 전체 구현의 개인 단독 성과 표기는 넣지 않았습니다. 이미지 5개 중 HTTP 카드는 설명용 도식입니다.
